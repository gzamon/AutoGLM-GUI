## 安装启动 AutoGLM-GUI 计划

### 步骤 1：克隆仓库
```bash
git clone https://github.com/suyiiyii/AutoGLM-GUI.git .
```

### 步骤 2：安装依赖（使用 uv）
```bash
uv sync
```

### 步骤 3：构建前端
```bash
uv run python scripts/build.py
```

### 步骤 4：启动服务
```bash
uv run autoglm-gui
```

### 前置要求
- Python 环境
- uv 包管理器（如果没有会提示安装）

### 启动后
- 访问 http://localhost:8000
- 在 Web 界面配置模型 API（支持智谱 BigModel、ModelScope 或自建服务）
